kz-skills: UI rules for AI coding agents, with checks that measure them

Stack-neutral UI/UX rules that tell an AI agent what any interface must do, what breaks when it does not, and a browser check that fails it. 57 UI rules, 6 motion rules, 21 chart rules, 10 diagram rules and 16 principles, in thirteen installable skills, with ten browser checks.

See every rule, live Install GitHub

It costs time and tokens on purpose: /kz-uiuxrule took 1.52x the time and 2.15x the tokens of no skills on Sonnet 5.5 (1.67x and 1.86x on Opus 5.5) and introduced 0 check failures against 50 (55). How it was measured

What agents get wrong, and the rule that catches it

  • A filter row that is an empty typed box under every columnRule T1, caught by table-check.js
  • A focus ring that is a rectangle round a curved chart wedgeRule C5, caught by layout-audit.js
  • A search field that re-renders on every keystroke, closing the phone keyboardRule F8, caught by typing-check.js
  • A label that is dark on dark, 1.04:1, in the dark theme onlyRule Y2, measured in both themes
  • A diagram label sitting on its own line, so the line strikes through the wordRule G6, caught by diagram-check.js
