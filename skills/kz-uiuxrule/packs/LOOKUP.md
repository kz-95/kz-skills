`python ../../kz-uicheck/scripts/run-checks.py page.html --checks <the pack's checks> --width 375 --scheme light`
Point it at the screen the work is on: `--hash ROUTE` opens page.html#ROUTE, `--tap "#tab,#open"` clicks in order, `--wait SELECTOR` must be visible first (also `--storage FILE`, `--expect TEXT`).
A run that reports WRONG SCREEN is a failure, not a clean result: the check never saw the work. Fix `--hash`, `--tap` or `--wait` and run it again.
